During CIS352 lecture, several students mentioned wanting more practice problems. We have written up another set of practice problems.

Programming with Algebra

  • Define f by ((f g) x) = (x (g 0)), now define f via a Racket lambda:
(define f (λ (g) ...))
  • Let foldl be defined by the following definition:
(foldl f a '()) = a
(foldl f a (cons hd rst)) = (foldl f (f hd a) rst)

Using equational reasoning, calculate the value of (foldl append '() '((x) (y)))
